# Storm for Windows

Electron build of Storm Browser (same brutalist design as the Android app).

## Build on GitHub (recommended)
Push a tag such as `v3.2` — the workflow builds `Storm-Setup-3.2.0.exe` and attaches it to the release next to the Android APK.

## Build on your own PC
    cd windows
    npm install
    npm start          # run it
    npm run dist       # make dist/Storm-Setup-*.exe
